# 横纵深度研究 Skill

一个面向 Codex 的深度研究 Skill：沿时间轴还原研究对象如何演进，再从当前切面分析竞品、替代方案、用户口碑与生态位，最后通过对抗式审查形成可追溯、可证伪的综合判断。

> **来源：数字生命卡兹克。** 核心“横纵分析法”与原始研究提示词来自数字生命卡兹克。本仓库是在该方法基础上的工程化改编，不代表原作者官方发布或背书。

## 它解决什么问题

普通的“深度调研”提示词容易出现四类错误：把新闻按日期堆成年表、先凭知名度挑竞品、把宣传材料当成独立事实，以及为了长篇幅补写无法验证的因果。

这个 Skill 将研究拆成一条有门禁的工作流：

1. 从每次调用中动态识别研究对象及其唯一身份；
2. 锁定研究截止日、对象类型和关键问题；
3. 建立候选事件、竞争集合与证据账本；
4. 纵向解释“背景—选择—结果—路径依赖”；
5. 横向比较直接竞品、间接替代、上一代方案与“不行动”；
6. 用反例、竞争性解释和可证伪条件挑战初稿；
7. 交付带来源与不确定性说明的长篇报告。

## 主要能力

- **动态对象绑定**：调用时直接写研究对象，不需要手工修改 Skill 文件中的占位符。
- **纵向因果叙事**：覆盖起源、诞生、关键演进、决策约束、失败和争议，不退化为流水账。
- **横向竞争分析**：先构建竞争集合，再判断无直接竞品、少量竞品或充分竞品。
- **证据分层**：区分一手材料、独立来源、社区反馈和聚合线索，并记录事件日与发布日期。
- **用户口碑校验**：区分用户类型、时间窗和样本偏差，不用少数帖子代表全体用户。
- **对抗式审查**：检查身份、时点、因果、数据口径、竞品可比性、幸存者偏差和反例。
- **自适应长篇输出**：复杂对象以 1 万至 3 万字为目标；证据不足时禁止为凑字数编造。

## 适用对象

- 产品与工具：Cursor、Claude Code、Hermes Agent
- 公司与组织：Anthropic、OpenAI、字节跳动
- 技术与概念：MCP、RAG、Agent 框架
- 人物：行业关键人物的职业轨迹及同期比较

## 安装

### 方法一：克隆后复制

```bash
git clone https://github.com/chen1pengvincent/research-horizontal-longitudinal.git
cp -R research-horizontal-longitudinal/research-horizontal-longitudinal ~/.codex/skills/
```

### 方法二：手动下载

下载仓库 ZIP，解压后把内层 `research-horizontal-longitudinal` 目录复制到 `~/.codex/skills/`。

安装后的关键路径应为：

```text
~/.codex/skills/research-horizontal-longitudinal/SKILL.md
```

若 Codex 尚未显示该 Skill，请在新任务中重新检查可用 Skill 列表。文件存在只证明安装产物已经落地，不自动证明当前运行实例已完成发现。

## 使用方法

在请求中显式调用 Skill，并直接写明要研究的对象：

```text
使用 $research-horizontal-longitudinal 深度调研 Cursor，截至 2026-08-05。
```

```text
使用 $research-horizontal-longitudinal 研究 MCP 协议的起源、关键演进与当前竞争格局。
```

```text
使用 $research-horizontal-longitudinal 调研 Anthropic，重点分析其战略转折、组织选择和与 OpenAI、Google DeepMind 的生态位差异。
```

对象清楚时，Skill 会直接开始研究；对象同名、缺失或同时出现多个主对象但关系不明时，才会提出一个阻塞性澄清问题。

## 输出结构

报告固定按以下顺序组织：

1. 研究范围、对象身份、截止日和来源口径；
2. 纵向分析：发展史叙事；
3. 横向分析：竞争与替代格局；
4. 横纵交汇：当前位置与未来走向；
5. 证据与不确定性附录；
6. 按主题组织的关键来源。

## 研究边界

- 除非明确要求使用封闭语料，否则完整研究依赖联网检索或可用的官方数据库。
- “关键节点”指足以改变技术、产品、商业、组织、采用、监管、声誉或竞争位置的事件，不等于收录全部新闻。
- 决策动机没有同期直接证据时，只能标为推断，并给出竞争性解释。
- 社区口碑只能说明样本中反复出现的主题，不能在没有系统抽样时冒充总体统计。
- 篇幅目标不得凌驾于证据完整性。

## 来源与改编说明

本 Skill 的核心分析框架和原始提示词来源于 **数字生命卡兹克**。

本工程化版本在原始方法上增加了：

- 研究对象的动态绑定与同名消歧；
- 研究截止日和实体身份锁定；
- 来源层级、证据账本与交叉核验；
- 竞品候选集合、入选标准与排除理由；
- 事实、争议、推断和未经证实信息分层；
- 反例搜索、竞争性解释和可证伪审查；
- 输出限制下的失败关闭规则。

这些改编旨在降低研究过程中的幻觉、口径混乱和结果倒推风险。
